変更要求: [`docs/P901-cr-direction/CR-003.md`](../P901-cr-direction/CR-003.md)

## スコープ決定(P903が着手前に記載)

### 影響カテゴリの分類

* [ ] UI表示文言のみ
* [ ] 画面項目追加・変更(バックエンド契約変更なし)
* [ ] API契約変更
* [ ] データモデル変更
* [ ] 非機能・インフラ変更
* 上記のどれにも当たらない。**内部構成の変更(Python パッケージの統合)のみ**。画面・API・データモデル・設定ファイルの形式・コンテナ構成は変えない。対応表の目安は使えないため、以下の判断を個別に記録する。

### 対象外としたフェーズ

| フェーズ | 再オープン不要と判断した理由 |
| --- | --- |
| P002 | 画面・API・データモデルを変えない |
| P004 | 要求 ID と設計箇所の対応は変わらない(REQ-ARCH-004・005 の対応箇所は P003 §2・§1.2 のまま) |

* ADR の扱い: ADR-007 の中心の決定「`server/` を 1 つの uv プロジェクトにする」は変わらず、パッケージの数だけが変わる。ADR を廃止して新しい ADR を起こすほどの決定の転換ではないため、ADR-007 を更新する(ADR-007 は CR-002 でも同じ扱いで 3 → 2 パッケージに更新している)。

## 【障害記録】

* 記録: `docs/test-records/20261014-0159-test-record.md`

* `e2e/scripts/run-suite.sh` で、A11 を性能の測定(A05・A08)の後、A06(HR のチェックサムの比較)の前に移す。A06 が最後に HR のデータを比べるので、A11 の操作でデータが変わらないことも引き続き確かめられる。期待値(3 秒)は変えない。

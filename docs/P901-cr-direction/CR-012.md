# CR-012 — 保存済み Query の一覧の [編集] を [名前変更] に変える

## 起票日

2026-10-16

## 起票者

プロジェクトの依頼者(Claude Code セッションでの指示、2026-10-16)。原文: 「Queryタブの保存済みQueryサブタブで、保存しているQuery の復元・編集・削除ができます。まず、編集を「名前変更」に変えてください。また、保存しているQueryのある行にマウスがあるときにマウスを右クリックすると「復元」と同じことが起きるようにしてください。」の前半

## 背景・課題

* 保存済み Query の一覧の各行にある [編集] は、名前と説明を変えるだけで SQL は変えない(`docs/P002-frontend-spec.md` §2.2.8)。ボタンの名前が「編集」だと、SQL を編集できるように見える。

## 変更要求の内容

* SC-02・SC-03 の Query タブ(サブタブ「保存済み Query」)の一覧の各行のボタン [編集] を [名前変更] に変える(`docs/P002-frontend-spec.md` §2.2.8)。
* 押したときの動作(ダイアログ「Query の名前と説明を変更」で名前・説明を変え、SQL は変えない)は変えない ★ACCEPTED★(2026-10-16 人間承認)検討: 原文はボタンの名前の変更だけを求めていると解し、説明を変える機能は残した/承認理由: 依頼者「このままでよいです」/残存リスク: ボタンの名前は「名前変更」だが説明も変えられる

## 期待する振る舞い

* 保存済み Query の一覧の各行に [復元]・[名前変更]・[削除] が並び、[編集] は無い。
* [名前変更] を押すと、ダイアログ「Query の名前と説明を変更」が開き、名前・説明を変えて保存できる(SQL は変わらない)。
* SC-03(PDB)の一覧も同じ。

# CR-008 — LLM で SQL を作るときの、LLM へのリクエストと LLM のリプライを表示するボタンを追加する

## 起票日

2026-10-14

## 起票者

プロジェクトの依頼者(Claude Code セッションでの指示、2026-10-14)。原文: 「LLMにSQL Query を作らせるとき、LLMへのリクエストとLLMのリプライを表示できるボタンを追加してほしい。」

## 背景・課題

* CR-007 で LLM に SQL を作らせられるようになったが、LLM に何を渡したか(システムの指示、スキーマの構造、データの例、要求)と、LLM が何を返したか(SQL を取り出す前の応答の全文)が画面から分からない。期待と違う SQL が返ったときに、原因(渡した構造の不足、要求の書き方、LLM の誤り)を確かめられない。

## 変更要求の内容

* Query タブ(SC-02・SC-03)の「LLM で SQL を作成」の部品に、直近の作成で LLM に送ったリクエストと LLM のリプライを表示するボタンを加える(`docs/P002-frontend-spec.md` §2.2.9)。
* `POST /api/llm/sql` の応答に、LLM に送ったリクエスト(システムの指示・ユーザーの文)と LLM のリプライ(応答の全文)を加える(`docs/P002-frontend-spec.md` §3.15、`docs/P003-backend-spec.md` §4.8)。

## 期待する振る舞い

* LLM で SQL を作成した後、「LLM とのやりとり」のボタンを押すと、LLM に送ったリクエスト(システムの指示と、スキーマの構造・データの例・要求を含むユーザーの文)と、LLM のリプライ(SQL を取り出す前の全文)が表示される。
* まだ作成していないときは、ボタンを押せない。
* LLM の応答から SQL を取り出せなかったとき(`LLM_ERROR`)も、リクエストとリプライを表示できる。時間切れなどでリプライが無いときは、リクエストだけが表示され、リプライが無いことが分かる。
* 表示した内容はコピーできる。
* 既存の LLM の作成・実行・保存済み Query などの振る舞いは変わらない。

## 影響が想定される範囲

P901時点での見積もりであり、確定した対応範囲ではない(確定は P903 が `docs/P903-cr-records/CR-008.md` に記録する)。

* 画面: SC-02・SC-03 の `LlmSqlPanel` にボタンと表示のダイアログ
* API: `POST /api/llm/sql` の応答に `exchange` を追加(後方互換の追加)。LLM のエラーの応答にも `exchange` を加える
* データモデル: 変更なし(リクエスト・リプライは保存しない)
* 関連ADR: ADR-018(LLM に渡す情報)。リクエストの内容(データの例を含む)を画面に返すことになる
